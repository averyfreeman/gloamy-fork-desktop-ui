# macOS 桌面应用：运行、安全与配对恢复

最后验证：**2026 年 11 月 11 日**。

Tauri 桌面应用复用现有 Vue 界面。只有在本机没有健康运行的 Gloamy 服务时，应用才会启动随应用提供的 daemon；如果已有健康服务，应用只连接它，不取得其所有权。桌面 WebView 连接 `127.0.0.1` 或 `::1`；本 POC 不支持绑定到特定非回环地址。

原生应用菜单显示 **Gloamy Desktop v0.1.1**。相邻菜单项通过私有控制套接字读取 gateway 版本；不提供该字段的旧版 daemon 会显示“未报告”。

## 服务生命周期

“关闭应用后继续运行 daemon”保存在桌面偏好设置中，默认关闭。关闭状态下，应用只会在 daemon 标记为由桌面应用启动时请求正常关闭。开启后，该 daemon 会继续运行，浏览器界面也可继续使用。未带桌面管理标记的服务（包括通过健康 HTTP API 连接的旧版服务）不会被桌面应用停止。

## 配对恢复

可在“身份验证”或“设置”中申请新的单次配对码，然后继续使用现有 `/pair` 流程。配对码通过当前用户专属的 Unix 控制套接字传输，仅保存在内存中，不会写入配置或日志。新配对会新增令牌哈希，不会撤销已有设备。关闭配对功能时无法申请配对码；HTTP 不提供生成配对码的接口。

## 本地控制与安全

套接字路径为 `$TMPDIR/gloamy-<uid>/control.sock`（或系统对应的临时目录），目录权限为 `0700`，套接字权限为 `0600`。协议只提供状态查询、申请配对码和正常关闭三种操作，不提供通用 shell 命令或配置写入。它隔离其他本机用户，但无法防御以同一用户运行的进程。daemon 现有的 bearer token 校验保持不变。

## 故障排查

- **地址已被占用：**停止占用配置主机和端口的服务，或修改 `~/.gloamy/config.toml` 中的 `gateway.host` / `gateway.port`。桌面应用不会启动重复 daemon。
- **无法恢复配对：**确认配对功能已启用，并在桌面应用中操作。浏览器无法访问本地控制套接字。
- **无法连接现有服务：**确认服务在配置的回环地址上健康运行。应用关闭时，未受桌面管理的服务仍会继续运行。

完整安全约定见[后端控制套接字安全契约](https://github.com/averyfreeman/gloamy-app-server-oauth2/blob/main/docs/security/desktop-control-socket.md)。
